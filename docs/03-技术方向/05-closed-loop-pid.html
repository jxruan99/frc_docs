闭环控制与 PID

FRC 机器人里，几乎每一个"转到某个角度""升到某个高度""保持某个速度"的动作，背后都是一个负反馈闭环。这一篇讲清楚 FRC 里闭环怎么做：PID 三项、前馈、运动曲线，PID 跑在主控制器还是电机控制器，以及怎么调参。

资料整理于 2026 年 10 月代码示例以 Java 为主

01为什么要闭环

以电梯为例。最简单的做法是给电机 6 伏电压、跑 1 秒，希望电梯升到 1 米。这叫开环控制：只管发指令，不看结果。问题是，电池电量、摩擦、道具重量每次都不一样，电梯有时停在 0.9 米，有时冲到 1.1 米。

闭环控制用编码器实时测量电梯的实际高度，和目标高度比较，根据误差不断调整电压。误差大就用力推，接近目标就减小力度，冲过头就往回拉。这种"用测量结果抵消误差"的方式叫负反馈，FRC 里绝大多数精确动作都靠它完成。

02控制回路长什么样

回路每个周期执行一次：读传感器 → 算误差 → 算电压 → 发给电机。主控制器上默认每 20 毫秒一次，智能电机控制器内部大约每 1 毫秒一次。

03PID 三项

u(t) = kP · e(t) + kI · ∫e(t)dt + kD · de(t)/dt

P 比例

kP × 当前误差

误差越大，推得越用力。是 PID 的主力。

太小：反应慢，可能停在半路。太大：冲过头，来回振荡。

I 积分

kI × 误差的累积

误差长时间存在，就越积越大，消除"差一点到不了"的稳态误差。

容易积分饱和，导致大幅过冲。FRC 里很少用，能用前馈解决的就不用它。

D 微分

kD × 误差的变化速度

误差缩小得很快时提前"踩刹车"，抑制过冲和振荡。

对传感器噪声敏感，太大会让电机抖动、发出噪音。

FRC 里最常见的组合是前馈 + P，或者前馈 + PD。PID 三项都用的情况反而不多。

04前馈：FRC 控制的"秘诀"

PID 只能"出现误差后再修正"。前馈则根据物理模型，事先算出达到目标大概需要多少电压。在 FRC 里，"前馈打底，PID 修余量"几乎是共识：前馈承担大部分工作，PID 的增益就可以调得很小，系统又快又稳。

电压 = kS · sgn(v) + kV · v + kA · a + 重力项
参数含义直观理解
kS静摩擦电压让机构"刚好开始动"需要的电压
kV速度系数每单位速度需要多少电压。电机越快，反电动势越大，需要的电压越高
kA加速度系数加速时额外需要的电压
kG重力项电梯：抵消重力的固定电压；手臂：乘以 cos θ，手臂水平时最大，竖直时为零

WPILib 提供了三种现成的前馈：SimpleMotorFeedforward（飞轮、底盘）、ElevatorFeedforward（电梯，带 kG）、ArmFeedforward（手臂，带 kG·cos θ）。这些参数不用猜，可以用 WPILib 的 SysId 工具实测出来，见第 09 节。

05运动曲线

如果目标从 0 米一下子跳到 1 米，PID 会瞬间给出很大的电压，机构猛冲出去，容易过冲，甚至损坏结构。运动曲线（Motion Profile）的做法是：把一次大的跳变拆成一连串平滑变化的小目标，让机构按"加速 → 匀速 → 减速"的节奏走过去。最常用的是梯形曲线：

07PID 跑在哪里

主控制器上没有专门的硬件 PID 模块。PID 是软件，可以跑在两个地方：

位置一：主控制器上的 WPILib 库

roboRIO、roboRIO 2.0 和 SystemCore 都一样，PID 由 WPILib 库提供，在机器人程序的主循环里计算。这些是纯数学库，和具体硬件无关，所以 2027 年换成 SystemCore 后依然可用。常用的类：

类作用
PIDController标准 PID；可设置误差容差，可用 enableContinuousInput 处理角度的首尾相接
ProfiledPIDControllerPID + 梯形运动曲线，目标值自动平滑过渡
SimpleMotorFeedforwardkS、kV、kA 前馈，用于飞轮、底盘
ElevatorFeedforward加上恒定重力项 kG
ArmFeedforward加上随角度变化的重力项 kG·cos θ
TrapezoidProfile单独生成梯形运动曲线

位置二：智能电机控制器内部

现在的无刷电机控制器（CTRE Talon FX、REV SPARK MAX / SPARK Flex 等）芯片里自带 PID 和前馈，大约以 1 kHz 的频率直接读电机编码器运算。主控制器只需要通过 CAN 发一个目标值。

主控制器（WPILib）电机控制器内部
计算频率约 50 Hz（每 20 ms）约 1000 Hz
响应和平稳度一般更好，适合高速机构
CAN 总线负担每个周期都要发电压指令只在目标变化时发一次
可用的传感器任何传感器：IMU、相机、外接编码器主要是电机编码器，或直接接到控制器上的传感器
适合需要综合多种传感器的高层回路：航向保持、视觉对准、路线跟踪单个机构的位置和速度回路：飞轮、电梯、手臂、swerve 轮组
常见组合

单个机构的回路交给电机控制器；需要融合 IMU、相机、里程计的高层回路放在主控制器上。高层回路算出的结果（比如"轮子应该朝 30° 方向、以 2 m/s 转"）再作为目标值发给电机控制器，形成"外环套内环"的串级控制。

08代码示例

下面三段示意代码分别对应三种写法。目的是说明结构，变量名和数值都是示例。

在主控制器上：WPILib PID + 前馈（手臂）

PIDController pid = new PIDController(0.8, 0.0, 0.05);   // kP, kI, kD
ArmFeedforward ff = new ArmFeedforward(0.1, 0.4, 1.2);   // kS, kG, kV

// 在 periodic() 里，每 20 ms 执行一次
double volts = pid.calculate(armAngleRad(), targetRad)   // 反馈：修正误差
             + ff.calculate(targetRad, 0.0);              // 前馈：抵消重力
armMotor.setVoltage(volts);

在电机控制器里：CTRE Phoenix 6（Talon FX）

// 配置一次增益（PID + 前馈）
talon.getConfigurator().apply(new Slot0Configs()
        .withKP(2.4).withKD(0.1)
        .withKS(0.1).withKV(0.12));

// 之后只需要发目标：转到第 10 圈
talon.setControl(new PositionVoltage(10.0));

在电机控制器里：REV（SPARK MAX / SPARK Flex）

SparkMaxConfig config = new SparkMaxConfig();
config.closedLoop.pid(0.1, 0.0, 0.0);
spark.configure(config, ResetMode.kResetSafeParameters, PersistMode.kPersistParameters);

// 发目标：转到第 10 圈
spark.getClosedLoopController().setReference(10.0, ControlType.kPosition);
版本提醒

上面电机控制器的代码按 2025–2026 年的厂商库写成。CTRE 和 REV 每年都可能调整接口，2027 年还会随 SystemCore 一起升级，实际使用时以当年的厂商文档为准。WPILib 的 PID 和前馈类相对稳定。

09调参流程

  1. 先在仿真里练手

    用 WPILib 的电梯或手臂仿真示例体会参数的影响，见《开发环境与仿真》的练习 3 和练习 4。

  2. 确认方向和单位

    给一个小电压，确认电机正转时编码器读数增大。方向反了，负反馈就变成正反馈，机构会越跑越远。同时搞清楚编码器读数的单位：圈、弧度还是米。

  3. 用 SysId 测前馈

    WPILib 的 SysId 工具让机构按预设方式运动，自动算出 kS、kV、kA、kG。没有 SysId 时，也可以手动找：慢慢加电压，记下机构刚开始动的电压，就是 kS 的近似值。

  4. 从小到大加 kP

    从很小的值开始，逐步加大，直到响应够快、开始出现轻微振荡，再往回收一些。

  5. 需要时加一点 kD

    还有过冲或振荡，就加一点 kD 增加阻尼。

  6. kI 尽量不用

    确实存在稳态误差、且前馈已调好时，才加一点 kI，并限制积分的作用范围（比如只在误差很小时才积分）。

  7. 加安全限制

    设置电流限制和软限位，防止参数调错时机构撞到极限位置或电机过热。

调参时一定要画曲线

用 AdvantageScope 同时画出目标值和实际值的曲线，过冲、振荡、迟滞一目了然，比肉眼看机构动作可靠得多。

10常见问题

机构一启用就猛冲到底，停不下来
多半是方向反了，形成了正反馈：电机反转、编码器方向或增益的正负号设错了。立刻禁用机器人，检查方向设置。
机构来回振荡，停不稳
kP 太大，或者 kD 不够。先减小 kP，再适当加 kD。也要检查机构是否有很大的间隙或回程差。
总是差一点到不了目标
通常是前馈不足，比如电梯没加 kG、手臂没加 kG·cos θ。先补前馈，不要急着加 kI。
在 WPILib 里调好的参数，搬到电机控制器里完全不对
两边的单位不同。WPILib 的 kP 取决于你传入的单位（比如弧度对应伏）；电机控制器里的 kP 通常是"每圈误差对应多少伏"或"多少占空比"。换位置时要重新换算或重新调。
电机发出高频噪音、发烫
kD 太大，放大了传感器噪声；或者机构停在目标附近时一直在小幅修正。减小 kD，适当设置误差容差。
换一块电池，表现就变了
电池电压会影响电机出力。用电压模式控制（如 setVoltage、PositionVoltage）代替百分比输出，可以自动补偿电压波动。
