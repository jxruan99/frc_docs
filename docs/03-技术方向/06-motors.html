电机与电机控制器

电机是机器人所有动作的来源，电机控制器决定电机怎么转。这一篇介绍 FRC 常用的无刷电机和控制器，怎么读电机特性曲线、选减速比，以及 CAN 配置、电流限制这些让机器人可靠运行的关键设置。

资料整理于 2026 年 10 月电机规格以厂商公布为准

01电机在机器人里的角色

一台典型的 FRC 机器人有十几个电机：swerve 底盘就要 8 个（每个轮组一个驱动、一个转向），再加上取件、传送、发射、升降、手臂、攀爬等机构。每个电机都配一个电机控制器，大多挂在 CAN 总线上，由主控制器统一指挥。

信号链路是：主控制器（发目标）→ 电机控制器（把电池的电按要求送给电机，常常还在内部跑闭环）→ 电机（产生扭矩）→ 减速箱（换成机构需要的速度和力量）→ 机构。闭环控制的部分见《闭环控制与 PID》。

02有刷电机与无刷电机

无刷电机必须配专门的控制器，因为换向要靠控制器完成。也正因为控制器知道转子在哪，它天然就能拿到精确的编码器数据，这是无刷电机在 FRC 普及的重要原因。

05读懂电机特性曲线

直流电机（包括无刷电机）在固定电压下有一个重要特性：扭矩随转速线性下降。转速为零时（堵转）扭矩最大，空载时转速最高、扭矩为零。输出功率是扭矩乘以转速，在空载转速的一半处达到最大。下图以 REV NEO 在 12 V 下的公布数据绘制：

  • 电流和扭矩成正比：扭矩越大，电流越大。电机接近堵转时电流可达上百安培，会让电池电压骤降、电机迅速发热
  • 机构不应长期工作在堵转附近：比如手臂顶着限位一直出力，或者底盘推着墙不放
  • 想要力量就要牺牲速度：这正是减速箱的作用

06减速比怎么选

电机转速很高、扭矩很小，必须经过减速才能驱动机构。减速比为 N:1 时：

机构转速 = 电机转速 ÷ N
机构扭矩 ≈ 电机扭矩 × N × 传动效率

以电梯为例：用一个 NEO 通过 10:1 减速箱带动直径 5 cm 的绳轮。电机输出 1.3 N·m 时（约为堵转扭矩的一半），绳轮扭矩约 13 N·m，拉力约 13 ÷ 0.025 ≈ 520 N，大约能提起 50 kg。这时电机约 2838 RPM，绳轮约 284 RPM，电梯上升速度约 0.74 m/s。实际还要扣掉摩擦和传动损耗，并留出余量。

选型工具

FRC 圈子里常用 ReCalc 在线计算器：选好电机型号、数量、减速比和机构参数，就能算出速度、加速时间和电流，比手算方便得多。

  • 底盘：减速比决定最高速度和加速能力之间的取舍。轮组厂商通常提供几档可选减速比
  • 手臂：通常需要很大的减速比（几十比一甚至上百比一），才能稳稳托住重量
  • 飞轮：要的是转速，减速比小，甚至是增速

07CAN 配置

  • 每个设备要有唯一的 CAN ID：同一类型的设备之间 ID 不能重复，否则程序会控制错电机。新设备出厂 ID 通常相同，上车前要逐个修改
  • 调试工具：CTRE 设备用 Phoenix Tuner X，REV 设备用 REV Hardware Client，用来改 ID、升级固件、单独测试电机
  • 升级固件：新设备和每个新赛季开始时，都要把固件升级到和软件库配套的版本
  • 总线拓扑：CAN 是一条串起来的总线，两端要有 120 Ω 终端电阻。配电板（如 REV PDH）上通常带有终端电阻开关
  • 多条总线：SystemCore 有 5 路 CAN-FD，可以把底盘和机构分到不同总线上，减轻单条总线的负担，也降低一处接线故障影响全车的风险
  • 记录和贴标签：把每个电机的 CAN ID、用途、所在总线整理成表，贴在电机上，方便比赛现场快速排查

08关键设置

设置作用建议
空闲模式没有指令时，Brake（制动）让电机锁住，Coast（滑行）让它自由转手臂、电梯用 Brake 防止下坠；飞轮常用 Coast
反转设置电机的正方向保证"正电压 = 机构往正方向走 = 编码器读数增大"
电流限制限制电机能抽取的电流每个电机都要设，详见下一节
跟随模式让一个电机完全跟随另一个电机的输出两个电机驱动同一机构时用。注意跟随者是否需要反向，方向设错两个电机会互相较劲
软限位编码器读数超过范围时，电机不再往那个方向出力电梯、手臂必设，防止撞到机械极限
减速比换算把电机圈数换算成机构的单位（米、度）在控制器里设置后，闭环目标可以直接用机构单位
保存配置让配置在断电后保留REV 需要显式保存（persist）；更稳妥的做法是程序每次启动时重新下发全部配置

09电流限制与掉电保护

全车十几个电机都从一块 12 V 电池取电。几个大电机同时用力时，总电流可能达到几百安培，电池电压会明显下降。电压掉得太低时，主控制器会进入掉电保护（brownout）：暂时降低或切断电机输出，机器人就会突然变得软弱无力，甚至短暂失控。

  • 两种电流限制：电源电流（supply current）是从电池取的电流，限制它能保护电池和断路器；定子电流（stator current）是流过电机线圈的电流，和扭矩成正比，限制它能防止电机过热、轮子打滑
  • 每个电机都要设电流限制：具体数值和机构有关，可以参考厂商推荐值和 ReCalc 的计算结果
  • 断路器：配电板上每路电机通常接 40 A 断路器，长时间超载会跳闸
  • 电池管理：每场比赛前换上充满的电池；用电池测试仪淘汰内阻大的旧电池
安全警告
  • SPARK MAX 等控制器可以设置电机类型（有刷或无刷）。把无刷电机误设成有刷模式可能损坏电机和控制器，配置时务必确认
  • 第一次测试新机构时，先用很小的电压和电流限制，确认方向正确再逐步放开
  • 调试时机器人周围不要站人，手要远离齿轮、链条和滚轮

10新电机上车流程

  1. 接线检查

    电源线接到配电板对应通道，CAN 线接入总线，确认极性和终端电阻。

  2. 升级固件、设置 ID

    用 Phoenix Tuner X 或 REV Hardware Client 升级固件，设置唯一 CAN ID，并记录到 CAN ID 表里。

  3. 单独测试

    在调试工具里低速转一下电机，确认它能转、方向正确、编码器读数随之变化。

  4. 写进程序

    在对应的子系统里创建电机对象，下发反转、空闲模式、电流限制、减速比、软限位等配置。

  5. 开环试车

    先用小电压开环驱动，确认机构动作方向正确，限位和软限位生效。

  6. 闭环调参

    测前馈、调 PID，见《闭环控制与 PID》的调参流程。

11常见问题

程序里控制了电机，但它一动不动
依次检查：CAN ID 是否和程序里一致、是否和别的设备重复；固件是否和软件库版本配套；机器人是否已启用；控制器指示灯显示什么状态（对照厂商说明书）。
两个电机一起驱动同一机构，发出怪声、发热
两个电机方向相反，在互相较劲。检查跟随模式下跟随者的反向设置。
电机很烫
长期在大电流下工作：减速比不合适、机构卡滞，或者手臂顶着限位一直出力。加电流限制，检查机械阻力，到位后减小保持电流。
比赛中机器人时不时"软"一下
多半是掉电保护被触发。查看 Driver Station 日志里的电压曲线，加强电流限制，换用好电池，检查电源线和接头是否松动。
断路器经常跳闸
该路电机长时间超载。检查机构是否卡住，降低电源电流限制，或者调整减速比。
