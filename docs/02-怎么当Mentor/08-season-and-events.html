家长 Mentor 学习计划 · 第二部分

赛季与比赛中的 Mentor

从 1 月初公布比赛题目，到三四月的比赛周末，是 mentor 最忙、也最容易"越位"的阶段。这一篇按时间顺序讲：开赛日怎么陪学生读题，build season 盯什么，比赛前要准备什么，比赛当天一场接一场的循环里 mentor 站在哪里，以及联盟选择和赛后复盘。

适合：随队参赛的 mentor 和家长比赛周末的整体流程见第一部分 §09

01开赛日

每年 1 月初，FIRST 在开赛日（Kickoff）公布当年的比赛题目和规则手册（Game Manual）。接下来几天的策略讨论，决定了整个赛季的方向。

  • 一起读规则。让学生分组精读手册的不同章节，再互相讲解。mentor 可以帮忙点出容易漏看的限制（尺寸、重量、越界、犯规）。
  • 先分析比赛，再想机器人。怎么得分最多？哪些动作性价比高？对手会怎么打？一支普通队伍在比赛里平均能做到什么？
  • 排优先级。列出机器人可能的能力，按"必须有 / 最好有 / 有了更好"排序。mentor 提醒学生对照自己的资源和能力，而不是对照顶尖队伍。
  • 忍住替他们定方案。你可能一眼看出最优策略，但这几天是学生学习分析问题的最好机会。用问题引导，让学生得出结论。

02Build Season

mentor 要盯的为什么
进度和里程碑学生普遍低估时间。每周对照里程碑检查，及早发现延误（见团队运营）
安全赶工时最容易出事，越到后期越要盯
设计评审在加工前发现问题，比做完再改便宜得多
驾驶练习时间驾驶员练习是最常被牺牲、但对成绩影响最大的环节之一
学生状态学业、睡眠、情绪；别让少数学生扛下所有工作
非技术工作奖项材料、赞助商更新、出行安排，同样有截止日期

03赛前准备

机器人

  • 按检录清单自查（尺寸、重量、电气、保险杠）
  • 备件清单和工具箱
  • 电池编号、充电计划
  • 代码已提交，有可回退的版本

维修区

  • 工作台、电源、照明
  • 队旗、展示材料、安全标识
  • 急救包
  • 维修区的分工和值班表

人和后勤

  • 上场队员、维修组、侦察组名单
  • 侦察表格或应用已测试
  • 奖项面试的分工和演练
  • 交通、住宿、饮食、同意书

04比赛日的循环

资格赛期间，每支队伍一天要打好几场，每一场都重复同样的循环。理解这个循环，就知道 mentor 在每一步该做什么。

05现场分工

角色谁来做说明
上场队员 Drive Team学生驾驶员、操作手、人类玩家；另有一名场边教练 Drive Coach场边教练可以由学生或成人担任，具体人数和资格以当年 Game Manual 为准。越来越多的队伍让学生担任
维修组 Pit Crew学生为主，mentor 支持负责检查、维修、电池；维修区人数通常有限制
侦察组 Scouting学生记录每支队伍每场的表现，为策略和联盟选择提供数据
评委访谈学生评委希望听学生讲，mentor 在场时尽量不插话
随队成人mentor 和家长安全、后勤、照顾情绪、和赛事工作人员沟通

06该做与不该做

该做

  • 守住安全：护目镜、电池、搬运
  • 帮学生管理时间和情绪
  • 输了比赛时，带头保持冷静和风度
  • 感谢裁判、志愿者和其他队伍
  • 确保每个学生都吃饭、喝水、休息
  • 机器人坏了，帮学生按优先级排查

不该做

  • 在维修区接管维修，学生站在一边
  • 对裁判判罚当众表达不满
  • 在评委面前替学生回答
  • 在看台上对驾驶员大喊指令
  • 批评联盟队友或对手
  • 只围着自己孩子转
对判罚有疑问

按规则流程由学生上场队员到指定位置向裁判询问，而不是 mentor 去场边争论。具体流程见当年 Game Manual。

07联盟选择

资格赛结束后，排名靠前的队伍挑选队友组成联盟进入淘汰赛。前一晚，侦察组和策略组通常要整理出一份挑选名单（pick list）。

  • 让学生用侦察数据讨论、排序，mentor 提问："这支队伍的稳定性怎么样？跟我们的机器人能互补吗？"
  • 帮学生准备好各种情况：我们是挑人的一方、被挑的一方、都没有被挑中。
  • 没被选上时，帮学生调整心态：在维修区帮助其他队伍、去看台为联盟加油，也是 FRC 精神的一部分。

数据工具可以参考 The Blue Alliance 和 Statbotics。

08赛后

  • 先庆祝。不管成绩如何，先肯定学生的付出。
  • 一周内复盘。机器人、策略、维修区流程、侦察、后勤，各做一次（方法见带学生的方法）。
  • 感谢。给赞助商发照片和战报，感谢家长和志愿者。
  • 为下一场比赛列改进清单。两场比赛之间往往有一到几周，是改进机器人的好时机。

09赛事志愿者

FRC 赛事几乎完全依靠志愿者运转：裁判、检录员、场地复位、排队引导、评委、维修区管理等等。不随队的家长也可以报名当志愿者，这是了解比赛、结识其他队伍的好方式。有些岗位（如裁判、检录员）需要培训和认证。报名入口在 FIRST 志愿者页面。
